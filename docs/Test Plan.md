## Common Definitions

- SGM10: SGM10 stands for shifted geometric mean with shift 10, which is computed by adding 10 to all data points, taking the geometric mean, and then subtracting 10.

## Plan on PDHG

### Estimation of Matrix K's 2-norm

- This test focus on the influence on the PDHG effect by the number of power iterations for estimating Matrix K's 2-norm.
- Try 3 or 4 different power iteration numbers in addition to the default number.
- Testing on two different solving tolerance: 1e-4 and 1e-8
- The output should contain a csv. Columns of the csv are:
  - Name: the name of the corresponding lp case.
  - Power Iterations Number: the number of power iterations executed for corresponding case.
  - K-multiplication Number: the number of K-multiplication executed when solving the case. For un-solved problem, the number should be the number when the algorithm hit the iteration upperbound.
  - Converged: Indicating the algorithm converge or not.
  - Corresponding solving tolerance. 
- The output should contain a plot. 
  - X-axis: The different Power Iteration Numbers.
  - Y-axis: The SGM10 of all cases' K-multiplication Number.

### Step size scale

- This test focus on the influence on the step size scale of the PDHG.
- Try the following numbers: 0.8, 0.85, 0.9 (default), 0.95
- Testing on two different solving tolerance: 1e-4 and 1e-8
- The output should contain a csv. Columns of the csv are:
  - Name: the name of the corresponding lp case.
  - Step size scale: the step size scale for corresponding case.
  - K-multiplication Number: the number of K-multiplication executed when solving the case. For un-solved problem, the number should be the number when the algorithm hit the iteration upperbound.
  - Converged: Indicating the algorithm converge or not.
  - Corresponding solving tolerance. 
- The output should contain a plot. 
  - X-axis: The different step size scale.
  - Y-axis: The SGM10 of all cases' K-multiplication Number.

### Primal weight

- This test focus on the influence on primal weight of PDHG.
- Try the following numbers: 0.9, 0.95, 1(default), 1.05, 1.1
- Testing on two different solving tolerance: 1e-4 and 1e-8
